# Sample notes

The JVM manages memory with automatic garbage collection. Objects that are no longer
reachable are reclaimed by the collector, so Java developers rarely free memory by hand.

Spring Boot simplifies building REST APIs in Java with auto-configuration and embedded servers.

Normalization organises a relational database to reduce redundancy: 1NF removes repeating
groups, 2NF removes partial dependencies, and 3NF removes transitive dependencies.
